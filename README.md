# Device Log Summarizer

A small Python CLI that summarizes device telemetry from a CSV, exports the results to JSON, and charts average temperature per device.

Requires Python 3.9+.

## Setup

```
pip install matplotlib pytest
```

## Files

| File | Purpose |
|---|---|
| `sanitize.py` | Section 1: `sanitize_readings()` cleans a list of mixed sensor values |
| `test_sanitize.py` | Tests for Section 1 |
| `summarize.py` | Section 2: CSV to per-device summary, JSON export, terminal table |
| `device_telemetry.csv` | Sample input (see note below) |
| `output.json` | Sample output from `summarize.py` |
| `plot_temps.py` | Section 3: bar chart of average temperature per device |
| `chart.png` | Sample chart generated by `plot_temps.py` |
| `PROMPT_LOG.md` | How AI tools were used |

## How to run

```
pytest test_sanitize.py
python summarize.py
python plot_temps.py
```

`summarize.py` accepts `--input` (default `device_telemetry.csv`) and `--output` (default `output.json`).

## What `summarize.py` does

1. Reads the CSV with `csv.DictReader`.
2. Skips and counts invalid rows: missing `device_id`, status not in ACTIVE/WARNING/ERROR, or a temperature that is blank, non-numeric, `nan` or `inf`.
3. Groups by `device_id` and computes total records, mean temperature and ERROR count.
4. Drops devices whose average temperature is strictly greater than 80.0.
5. Writes the results to JSON (averages rounded to 2 decimals) and prints a summary table.

## Note on the input data

No `device_telemetry.csv` was attached to the assignment, so I created a sample. It includes deliberately bad rows and one device above the 80.0 cutoff to exercise the error handling and the filter.

## Assumptions

- Temperatures are in °C (the brief does not state a unit).
- Negative temperatures are valid in Section 2, since a negative temperature can be a real reading. Section 1 drops negatives because the brief defines them as error flags there.
- A device averaging exactly 80.0 is kept.

## Error handling that was tested

- Missing input CSV: clean error message, exit code 1.
- Empty CSV or missing required columns: clean error message, exit code 1.
- Bad rows: skipped and counted.
- Every device filtered out: writes `[]` and prints a message.
- `plot_temps.py` with a missing, invalid or empty `output.json`, or with entries missing `device_id` or a numeric `avg_temperature`: clean error message, exit code 1, no chart created.
